# Writing standards — Stock Market Mastery documents

## Product rule

**Output learning documents only.** Never scaffold web apps, APIs, databases, or per-company application code. Every company curriculum is a folder of Markdown (and optional EPUB).

## Voice

- Teach a motivated beginner → intermediate investor.
- Plain English first, then a precise formal definition.
- No hype, no “buy/sell” recommendations, no price targets framed as advice.
- Prefer primary filings over secondary blogs. Label estimates clearly.

## Every concept block (required)

For each concept in a layer lesson, include all of:

1. **Anchor question** — what the learner should be able to answer
2. **Plain English** — 2–4 sentences
3. **Formal definition** — precise terms
4. **Formula** (when applicable) — with units
5. **Reference range** — inline next to any ratio/metric (never a bare number)
6. **Worked example** — company-specific numbers with citation
7. **Common mistake** — one concrete misconception
8. **DIY check** — one short self-test prompt
9. **Citation** — see [citation-rules.md](citation-rules.md)

## Density targets

| Layer | Concepts | Mastery checklist items | Quiz questions |
| ----- | -------- | ----------------------- | -------------- |
| 1–7   | 3–6      | 8–12                    | 10             |

## Forbidden

- Invented financial figures presented as fact
- Mixing another company’s demo numbers into a live ticker
- Uncited “everyone knows” industry stats
- Dumping raw XBRL without teaching
- Investment advice language (“you should buy”)

## Cross-cutting link

End every layer document with one sentence that bridges to the next layer’s central question (funnel continuity).

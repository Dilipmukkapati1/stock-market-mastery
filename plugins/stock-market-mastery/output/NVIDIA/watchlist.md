# Reader Watchlist — NVIDIA (NVDA)

Standing requests from the owner for **anything** produced about this company — a book, an EPUB, an answer in chat. This file lives in the repo so any agent picks it up. Read it before producing work on NVIDIA; cover every OPEN item (or state plainly why it cannot be covered); check items off here when an edition addresses them.

## Always include

- **Silicon performance.** Current data-center GPU generation: architecture, headline specs (compute, memory capacity and bandwidth, interconnect), and measured performance vs the prior generation — from dated, credible sources (NVIDIA disclosures, MLPerf, reputable trade press), labeled as disclosed vs measured vs estimated.
- **Tokens-per-dollar.** Inference economics compared across the field: tokens per dollar (and, where available, performance per watt) for NVIDIA's current parts vs **Google TPU** (Ironwood / TPU 8 line), **Amazon Trainium**, **AMD Instinct (MI series)**, and other relevant custom silicon — from dated third-party benchmarks (e.g., InferenceX, SemiAnalysis, MLPerf) where they exist, always labeled as third-party measurement, never presented as NVIDIA-disclosed fact. This is the owner's headline comparison; no NVIDIA book is complete without it.
- **Custom-silicon risk tracker.** Where the cloud providers' in-house programs stand (Google TPU, Amazon Trainium/Inferentia, Microsoft Maia, Meta MTIA, Broadcom's ASIC business) and the CSP share of NVIDIA's data-center revenue — in absolute dollars and as a percentage, per quarter where disclosed or credibly estimated. (The owner noticed the CSP percentage falling while NVIDIA's revenue rises; keep tracking both numbers, not just the narrative.)
